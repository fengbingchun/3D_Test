# 3D_Test
## This project contains some 3D test code:
- Open3D's usage [isl-org/Open3D](https://github.com/isl-org/Open3D)
- VTK's usage [VTK](https://gitlab.kitware.com/vtk/vtk)
- PyVista's usage[PyVista](https://github.com/pyvista/pyvista)
## Python code
### Open3D
- Installation(Anaconda)
    ```
    conda create -n open3d python=3.10
    conda activate open3d
    pip install open3d
    ```
- Code
    - [Open3D basic examples](python/test_open3d.py)
### VTK
- Installation(Anaconda)
    ```
    conda create -n vtk python=3.10
    conda activate vtk
    pip install pyvista # PyVista depends on VTK
    pip install colorama
    ```
- Code
    - [VTK basic examples](python/test_vtk.py)
    - [PyVista basic examples](python/test_pyvista.py)
